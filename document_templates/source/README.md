# Document template sources

Исходные HTML/DOCX-шаблоны документов, которые использовались при сборке визуальных документов в приложении.

Эта папка хранится в git, потому что файлы являются исходниками проекта.

Runtime backup, примеры сканов, временные PDF и APK лежат в `references/` и не пушатся в git.
